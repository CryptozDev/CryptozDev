### 🚀 About Me

* 🎓 กำลังศึกษาระดับปริญญาตรี สาขาวิทยาการคอมพิวเตอร์และนวัตกรรมการพัฒนาซอฟต์แวร์
* 💻 **Frontend Focus:** มีความเชี่ยวชาญในการสร้าง UI ที่ตอบสนองได้ดีด้วย React.js, Vite, Tailwind CSS และ JavaScript
* ⚙️ **Backend & Database:** ออกแบบ REST API, Authentication System และ CRUD Operations ด้วย Node.js (Express) และ C# ร่วมกับ MySQL / MongoDB
* 🤖 **AI & Automation:** สนใจเทคโนโลยีสมัยใหม่ มีประสบการณ์สร้าง Web Chatbot เชื่อมต่อ OpenAI API, n8n Automation และ Discord Bot
* 🛠️ **DevOps & Tools:** ทำงานร่วมกันผ่าน Git/GitHub, ทดสอบ API ด้วย Postman, ใช้งาน Docker และออกแบบ UI/UX ด้วย Figma
* 🎯 **Goal:** มุ่งมั่นพัฒนาทักษะตนเองอยู่เสมอ พร้อมเรียนรู้เทคโนโลยีใหม่ๆ และมองหาโอกาสในการร่วมงานเพื่อพัฒนาผลิตภัณฑ์ระดับคุณภาพ
